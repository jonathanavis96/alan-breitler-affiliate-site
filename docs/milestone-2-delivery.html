How to Update a Link (3 Steps)

1
Open data/affiliates.json

Use any text editor (Notepad, VS Code, TextEdit). Find the product you want to update.

2
Replace the destination URL

Swap the placeholder URL with your real affiliate tracking URL from the network dashboard. Also change "placeholder": true to "placeholder": false.

Before:

"destination": "https://chat.openai.com/upgrade?ref=REPLACE_WITH_YOUR_TRACKING_ID",
"placeholder": true

After:

"destination": "https://openai.sjv.io/c/YOUR_REAL_ID/YOUR_CAMPAIGN/openai",
"placeholder": false
3
Rebuild and redeploy

Run npm run build in the project folder, then upload the dist/ folder to your hosting. Test each link by visiting yoursite.com/go/product-name/ to confirm it redirects correctly.

Good to know: Until you add real tracking URLs, the placeholder links still send visitors to the correct product websites — they just won't be tracked for commissions. There's no rush. Update each one as you get approved by the network.

7. How to Make Common Updates

Update a Product Score or Verdict

  1. Open data/products.json
  2. Find the product by its "slug" value
  3. Edit the "scores", "pros", "cons", or "verdict" fields
  4. Run npm run build and redeploy

Update Review Content

  1. Open the relevant file in content/reviews/ (e.g., chatgpt-plus.mdx)
  2. Edit the article text (written in Markdown format)
  3. Run npm run build and redeploy

Disable an Affiliate Link

  1. Open data/affiliates.json
  2. Find the product and set "active": false
  3. Run npm run build and redeploy

Change Site Branding

  1. Open data/site.json
  2. Update the "name", "tagline", or "description" fields
  3. Run npm run build and redeploy

Important: After any file change, you must rebuild the site with npm run build and upload the updated dist/ folder to your hosting. The site is statically generated — changes to data files only take effect after a rebuild.

Rebuilding the Site

When you need to push updates:

  1. Make your changes to data files or content
  2. Open a terminal in the project folder
  3. Run npm run build
  4. The built site appears in the dist/ folder
  5. Push to GitHub (or upload dist/ to your host)

Moving to a Custom Domain

When you're ready to use a custom domain (e.g., aifocus.com):

  1. Purchase a domain from any registrar (Namecheap, GoDaddy, etc.)
  2. Point the domain's DNS to your hosting provider
  3. Update the site value in astro.config.mjs to your new domain
  4. If no longer using a subdirectory, update the base value to '/'
  5. Rebuild and redeploy
Good to know: The site can be deployed anywhere that serves static files — GitHub Pages, Netlify, Vercel, Cloudflare Pages, or even a basic web host. No server-side code or database required.
